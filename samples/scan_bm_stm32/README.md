# scan_bm_stm32 — nRF70 Wi-Fi Scan on STM32U073RCTX (Bare Metal)

Demonstrates Wi-Fi scanning with the nRF70 BM library running on an STM32U073RCTX
microcontroller without any RTOS, using the STM32 HAL and a cooperative superloop.

---

## Hardware Requirements

| Signal        | STM32U073 Pin | nRF7002 Pin |
|---------------|---------------|-------------|
| SPI1 SCK      | PA5           | SPI_CLK     |
| SPI1 MISO     | PA6           | SPI_MISO    |
| SPI1 MOSI     | PA7           | SPI_MOSI    |
| CS (bit-bang) | PA4           | SPI_CS      |
| BUCKEN        | PC0           | BUCKEN      |
| IOVDD_CTRL    | PC1           | IOVDD_CTRL  |
| HOST_IRQ      | PB0           | HOST_IRQ    |
| UART2 TX      | PA2           | —           |
| GND           | GND           | GND         |
| 3.3V          | 3.3V          | VDD (via IOVDD) |

> **Adjust pin assignments** in `nrf70_stm32_shim/config/nrf70_bm_board_config.h`
> to match your schematic.

## Software Prerequisites

- STM32CubeIDE ≥ 1.14 (or any GCC-ARM toolchain + CMake)
- STM32CubeU0 HAL library (generated by CubeMX or downloaded separately)
- This repository (nrf70-bm) checked out with submodules:
  ```sh
  git clone https://github.com/nrfconnect/nrf70-bm
  cd nrf70-bm
  git submodule update --init --recursive
  ```

## STM32CubeIDE Integration

### 1. Create a new STM32 project

1. Open STM32CubeIDE → *File → New → STM32 Project*
2. Select device `STM32U073RCTX`
3. Accept default settings, name the project `scan_bm_stm32`

### 2. Configure peripherals in CubeMX

Open the `.ioc` file and configure:

**SPI1** (Connectivity → SPI1)
- Mode: Full-Duplex Master
- Hardware NSS: Disabled (bit-banged CS)
- Data Size: 8 Bits
- First Bit: MSB First
- CPOL: Low, CPHA: 1 Edge (Mode 0)
- Prescaler: set so BAUD ≤ 8 MHz initially (Prescaler 8 → 6 MHz @ 48 MHz SYSCLK)

**GPIO Outputs** (Pinout → right-click each pin → GPIO Output)
- PA4 → GPIO_Output (CS, label: NRF70_CS)
- PC0 → GPIO_Output (BUCKEN, label: NRF70_BUCKEN)
- PC1 → GPIO_Output (IOVDD_CTRL, label: NRF70_IOVDD)

**GPIO EXTI Input**
- PB0 → GPIO_EXTI0 (rising edge, label: NRF70_IRQ)
- Enable EXTI0 in NVIC → priority 5

**USART2** (Connectivity → USART2)
- Mode: Asynchronous
- Baud Rate: 115200
- PA2=TX, PA3=RX

**Clock** (Clock Configuration)
- HSI 16 MHz → PLL → 48 MHz SYSCLK (or higher, up to 56 MHz)

Generate code (*Project → Generate Code*).

### 3. Add nrf70_stm32_shim sources

In STM32CubeIDE:
1. *Project → Properties → C/C++ Build → Settings → Tool Settings*
2. Under *MCU GCC Compiler → Include paths*, add:
   ```
   ${workspace_loc}/nrf70_stm32_shim/include
   ${workspace_loc}/nrf70_stm32_shim/config
   ${workspace_loc}/nrf70_bm_lib/include/common
   ${workspace_loc}/nrf70_bm_lib/include/system
   ${workspace_loc}/nrf_wifi/os_if/inc
   ${workspace_loc}/nrf_wifi/fw_if/umac_if/inc
   ${workspace_loc}/nrf_wifi/fw_if/umac_if/inc/default
   ${workspace_loc}/nrf_wifi/hal/inc
   ${workspace_loc}/nrf_wifi/lmac_if/inc
   ${workspace_loc}/nrf_wifi/utils/inc
   ${workspace_loc}/sdk-nrfxlib/nrf_wifi/hw_if/hal/inc
   ```
3. Under *MCU GCC Compiler → Preprocessor*, add define:
   ```
   CONFIG_NRF70_ON_SPI=1
   ```
   (or rely on `autoconf.h` included via forced include)
4. Add a *Forced Include* file (optional, avoids adding `#include "autoconf.h"` everywhere):
   - *Miscellaneous*: `-include ${workspace_loc}/nrf70_stm32_shim/config/autoconf.h`

### 4. Add source files

Add to the Eclipse project (drag-and-drop into *Project Explorer* or *File → Import*):

**Shim sources:**
```
nrf70_stm32_shim/source/bus/spi_if.c
nrf70_stm32_shim/source/platform/rpu_hw_if.c
nrf70_stm32_shim/source/os/shim.c
nrf70_stm32_shim/source/os/timer.c
nrf70_stm32_shim/source/os/work.c
```

**BM library sources:**
```
nrf70_bm_lib/source/common/nrf70_bm_core.c
nrf70_bm_lib/source/system/nrf70_bm_lib.c   (and any other .c in system/)
```

**nrf_wifi OS-agnostic driver sources** — exact file list for scan-only mode
(do NOT use wildcards; files in `system/tx.c`, `fmac_peer.c`, `radio_test/`,
etc. require `NRF70_STA_MODE` / `NRF70_DATA_TX` and must NOT be included):

Common files (always required):
```
nrf_wifi/os_if/src/osal.c
nrf_wifi/utils/src/list.c
nrf_wifi/utils/src/queue.c
nrf_wifi/utils/src/util.c
nrf_wifi/hw_if/hal/src/common/hal_api_common.c
nrf_wifi/hw_if/hal/src/common/hal_fw_patch_loader.c
nrf_wifi/hw_if/hal/src/common/hal_interrupt.c
nrf_wifi/hw_if/hal/src/common/hal_mem.c
nrf_wifi/hw_if/hal/src/common/hal_reg.c
nrf_wifi/hw_if/hal/src/common/hpqm.c
nrf_wifi/hw_if/hal/src/common/pal.c
nrf_wifi/bus_if/bal/src/bal.c
nrf_wifi/bus_if/bus/qspi/src/qspi.c
nrf_wifi/fw_if/umac_if/src/common/fmac_cmd_common.c
nrf_wifi/fw_if/umac_if/src/common/fmac_api_common.c
nrf_wifi/fw_if/umac_if/src/common/fmac_util.c
```

Scan-only specific files:
```
nrf_wifi/fw_if/umac_if/src/system/rx.c
nrf_wifi/fw_if/umac_if/src/system/fmac_vif.c
nrf_wifi/fw_if/umac_if/src/system/fmac_api.c

nrf_wifi/fw_if/umac_if/src/system/fmac_event.c
nrf_wifi/hw_if/hal/src/system/hal_api.c
```

**Replace generated main.c** with:
```
samples/scan_bm_stm32/Core/Src/main.c
```
(copy into `Core/Src/main.c` of your CubeIDE project, or adapt the USER CODE blocks)

### 5. Firmware binary

The nRF70 firmware patch blob lives in `sdk-nrfxlib/nrf_wifi/bin/`. Convert to a C
array and add to your project:

```sh
xxd -i sdk-nrfxlib/nrf_wifi/bin/scan_only/nrf70.bin > Core/Src/nrf70_fw.c
```

Then adjust the symbol name in `nrf70_fw.c` to match what `nrf70_bm_core.c` expects
(usually `nrf70_fw_data[]` and `nrf70_fw_size`).

Alternatively, use GCC's `incbin` to embed the binary directly:

```c
extern const uint8_t nrf70_fw_data[] asm("_binary_nrf70_bin_start");
extern const uint32_t nrf70_fw_size  asm("_binary_nrf70_bin_size");
```

### 6. Build and flash

Click *Build* (Ctrl+B) and resolve any remaining include-path issues. Then:

```
Run → Debug (F5)
```

or use `st-flash` / OpenOCD to flash the `.elf`.

## Verification Checklist

1. **Build passes** — zero errors, zero undefined references to shim symbols
2. **UART shows firmware load success** — `nrf70_bm_sys_init()` returns 0
3. **Scan results appear** — SSIDs / BSSIDs printed in the callback
4. **Logic analyser** — SPI traffic shows 0x02 write opcode and 0x0B read opcode
5. **GPIO toggle** — HOST_IRQ EXTI fires; add a GPIO toggle in `nrf70_host_irq_handler()`
   to confirm on an oscilloscope

## Troubleshooting

| Symptom | Likely cause |
|---------|-------------|
| `rpu_init failed` | BUCKEN/IOVDD_CTRL GPIO not clocked; check `__HAL_RCC_GPIOx_CLK_ENABLE()` |
| `RPU not awake` | SPI wiring; verify CS/SCK/MOSI/MISO connections with logic analyser |
| No scan results | HOST_IRQ not firing; check EXTI config and NVIC priority |
| Hardfault | Stack overflow in ISR or heap exhaustion; increase heap in linker script |
| printf not working | USART2 not enabled; check `MX_USART2_UART_Init()` and `_write()` redirect |
